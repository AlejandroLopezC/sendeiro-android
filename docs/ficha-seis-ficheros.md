# Actividad 1 · Ficha de los seis ficheros

| Fichero | Función | ¿Se versiona? |
|---|---|---|
| `app/src/main/AndroidManifest.xml` | Declara componentes, permisos, tema y opciones de copia de seguridad. | Sí |
| `app/build.gradle.kts` | Configura el módulo Android, SDK, identificador, versiones y dependencias. | Sí |
| `gradle/libs.versions.toml` | Centraliza versiones de plugins y bibliotecas. | Sí |
| `MainActivity.kt` | Conecta controles, eventos, ciclo de vida, validación, permiso y listado. | Sí |
| `res/layout/activity_main.xml` | Define la estructura visual y restricciones del formulario. | Sí |
| `res/values/strings.xml` | Centraliza textos y mensajes de la interfaz. | Sí |

`build/`, `local.properties` y los almacenes de claves no se versionan.
